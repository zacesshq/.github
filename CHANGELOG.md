### Changed

- The organisation profile lists ten code themes: the eight contrast themes plus Warm Dark and Warm Light, the gentler pair with a 4.5:1 floor.
- The organisation profile shows Scenes 1.1.0 and Games 1.1.0 in the roadmap, describes the 65 scenes drawn as pixel art in any of the ten themes and adds the gentle warm reading view to the reading profile presets.
- The growth table on the organisation profile carries the releases from 3 to 8 November 2026: version 1.0.0 of the code themes and Profile, 1.1.0 of Scenes and Games and 0.2.0 of the reader.
- The website row on the organisation profile links the [studio](https://zacess.com/studio/) for trying every theme, scene, game and starter profile.
- `AI_POLICY.md`, linked from the README and SUPPORT.md.
- Community files follow the [AI policy](https://github.com/zacesshq/.github/blob/main/AI_POLICY.md): pull requests declare AI use and issue forms ask whether AI helped. Security reports go to security@zacess.com.

- The Ideas and Q&A discussion forms offer Accessibility profile, Code themes, Terminal scenes and Terminal games as areas.
- The organisation profile lists the [profile](https://github.com/zacesshq/profile) repository, links its issue forms and gives support@zacess.com for help with a product.

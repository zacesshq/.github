# zacesshq/.github

Organisation-wide files for [Zacess](https://github.com/zacesshq).

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The organisation profile shown on [github.com/zacesshq](https://github.com/zacesshq) |
| [`ACCESSIBILITY.md`](ACCESSIBILITY.md) | The accessibility commitments every Zacess repository works to |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct for every repository without its own |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guide and when contributions open |
| [`SECURITY.md`](SECURITY.md) | Default security policy |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Sends questions and feedback to Discussions until issues open |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Reminds contributors where pull requests go and to sign off their commits |

GitHub uses these files for any repository in the organisation that does not have its own copy. This repository also hosts the organisation's [Discussions](https://github.com/zacesshq/.github/discussions).
